## 字体使用声明

本站优先使用原来的 Courier New（英文）及宋体 / SimSun（中文），取自访问者设备的已安装字体。设备缺少原字体时，使用「文泉驿点阵宋体 TTF」16px 版本作为后备。字体完整保存在 overarching/fonts 中，通过网站自身加载。采用 16px 点阵版本，不代表所有文字的显示字号都固定为 16px。
